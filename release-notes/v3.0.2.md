## Changelog

- Make PowerShell setup inspect both the current-host profile and its all-hosts sibling before writing. Duplicate or custom cached initialization now produces an actionable warning, leaves every profile unchanged and exits nonzero.
- Extend `--doctor` with duplicate-profile and custom cached-initialization diagnostics while keeping the existing alias-format check.
- Add blocking `govulncheck` and audited gosec G115 checks to PR and main CI, plus scheduled full gosec reports on Linux and Windows.
- Remove avoidable integer narrowing in UTF-16 encoding, close-match ASCII detection and ConPTY result handling, with explicit exceptions for Windows process IDs and signed console coordinates.
- Document the reliable PowerShell reload flow and warn against caching context-sensitive `go-fuck --alias` output.
