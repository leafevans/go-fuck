## Changelog

- Add `--preview` to inspect corrections without re-running the original command, opening the selector, applying rule actions, or updating shell history. Combine it with `--json` or provide captured output with `--output-from`.
- Show rule explanations and pre-run actions in the terminal and fzf. JSON adds optional `reason` and `side_effect_description` fields without changing schema version 1.
- Escape bidirectional controls and Unicode line separators in terminal displays without changing the underlying command. Bash aliases no longer add empty correction results to history.
