## Changelog

- Git corrections preserve quoted paths and global repository options. For example, `git log -1 master -- docs/master.md` now suggests `git log -1 main -- docs/master.md` when Git reports a bad revision.
- Unknown-option corrections stop at `--`. Even long lists of paths after the separator add no allocations to option lookup.
- Branch, tag, remote and submodule suggestions look up candidates in the repository selected by `-C`. Worktree corrections quote the selected path for the active shell.
- Correcting a mistyped `git branch` flag no longer prepends a force-delete. Push upstream hints also handle empty arguments and quote the remote and branch separately.
- The confirmation prompt and fzf selector use consistent command escaping and side-effect labels.
- Diff suggestions distinguish literal filenames after `--` from options and recognize `--cached` as an alias for `--staged`. Submodule path suggestions preserve spaces in filenames.
