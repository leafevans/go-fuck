## Changelog

- Speed up `--help`, ordinary `--version`, and the text rule list by deferring executable discovery until a command needs rule availability. The JSON rule list keeps the same schema and default flags.
- Reduce Windows shell detection overhead and avoid unnecessary filesystem checks, sorting, and allocations when selecting rules and organizing corrections.
- Speed up fuzzy command matching by pruning candidates that cannot enter the shortlist.
- Fix positional edits in non-Git correction rules so unrelated arguments are preserved. Building Git push corrections now avoids an intermediate string without changing quoting or output.
