## Changelog

- Git rule edits now share exact subcommand, operation and argument spans. Branch, fetch, stash, merge, pull, remote, switch and checkout suggestions preserve `-C`, `--git-dir`, quoted arguments and unrelated words that happen to match the text being corrected.
- Git argument tests now cover Generic, Bash, Zsh, Fish, Tcsh and PowerShell. Tcsh has a dedicated splitter for history expansion and newline escapes, and the scheduled fuzz target exercises all six parsers.
- The WSL fallback installer is executed directly in tests. Successful replacement, checksum failure, corrupt archives, incorrect versions, symlink payloads and final rename failures all verify that a failed update preserves the installed binary.
- CI now installs the published package through Scoop on Windows, in addition to the existing Homebrew and AUR installation checks.
