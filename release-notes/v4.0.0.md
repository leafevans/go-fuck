## Changelog

- Move the Go module to `github.com/leafevans/go-fuck/v4`. Existing `/v3` installs remain on the 3.x series.
- Make commit reset, commit amend and port-owner termination explicit opt-ins. An occupied port alone is not grounds to terminate another service.
- Reuse existing Git branches without deleting them and require a local hook failure diagnostic before suggesting `--no-verify`.
- Avoid unrelated mkdir, rm, missing-copy-source and SSH authentication corrections.
- Keep the settings format and JSON schema version 1. See [the upgrade guide](https://github.com/leafevans/go-fuck/blob/v4.0.0/UPGRADING.md#upgrading-from-3x-to-400) for configuration changes.
