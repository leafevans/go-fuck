## Changelog

- WSL updates now execute through `sh` explicitly, so Fish users no longer need to change their login shell. If WSL cannot reach GitHub, the Windows updater downloads the Linux archive and verifies its SHA-256 checksum before WSL verifies it again and installs atomically.
- Fish quoting and escaped spaces are handled consistently with Bash and PowerShell when locating Git arguments. Literal `?` characters are no longer confused with the shell splitter's former escaped-space sentinel.
- A new Git argument fuzz target exercises quoted paths across Bash, Fish and PowerShell. Zero-allocation option parsing and long-path workloads are now enforced by the benchmark guard.
