## Changelog

- Add terminal capture (instant mode) for fish on Linux and macOS. `go-fuck --setup --capture-mode=instant` (or the manual `go-fuck --alias --capture-mode=instant --enable-experimental-instant-mode | source` line) starts a logged fish shell, so `fuck` reads the failed command output from the terminal log instead of running it again. Bash, zsh and PowerShell are unchanged.
