## Changelog

- Make zero-rerun capture the default on supported Bash, Zsh and PowerShell setups, with automatic fallback to rerunning when terminal capture is unavailable.
- Add `capture_mode` with `auto`, `instant` and `rerun` policies, plus the matching `--capture-mode` flag and `GOFUCK_CAPTURE_MODE` environment variable.
- Add `--explain` to report capture provenance, matching rules, explanations, side effects and execution order without executing anything.
- Upgrade generated aliases to format 4 so consecutive alias calls are skipped when locating the previous real command, including PowerShell and WSL usage.
- Expand `--doctor` with capture-policy, alias-version and runtime/shell compatibility diagnostics.
- Add optional JSON `capture_source` metadata while preserving schema version 1 and existing fields.
- Move the Go module and `go install` path to `github.com/leafevans/go-fuck/v3`.
